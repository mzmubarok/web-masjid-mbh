# Project Overview

**Project Name:** Masjid Baitul Hikmah Website
**Version:** 1.0
**Status:** Planning

---

# Introduction

Masjid Baitul Hikmah Website is a modern mosque information system designed to provide accurate, transparent, and easily accessible information for the community.

The website serves as the official digital platform for Masjid Baitul Hikmah Gondolayu Lor, supporting mosque administration, community engagement, financial transparency, and public communication.

The system includes a public-facing website and an integrated Content Management System (CMS) for administrators.

---

To build a modern, trustworthy, and sustainable digital platform that strengthens the relationship between the mosque and its community.

# Target Users

The system serves two primary user groups.

## Public Visitors

Visitors can:

- View prayer schedules.
- Read mosque information.
- Explore events.
- Browse photo galleries.
- Access financial transparency.
- Learn about donation programs.
- Find mosque location and contact information.

---

## CMS Administrators

Administrators can:

- Manage website content.
- Publish events.
- Update financial reports.
- Upload galleries.
- Manage donation programs.
- Configure prayer schedules.
- Manage media assets.
- Manage users and permissions.

# Project Scope

This project includes:

- Public Website
- CMS
- Authentication
- Role-Based Access Control (RBAC)
- Media Management

- Audit Logging

The initial release does not include:

- Online donations
- Payment gateway integration
- Mobile application
- Multi-language support

These features may be introduced in future versions.
